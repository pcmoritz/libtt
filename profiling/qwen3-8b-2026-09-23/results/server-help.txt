                        The format of the model weights to load. "auto" will
                        try to load the weights in the safetensors format and
                        fall back to the jax format if safetensors format is
                        not available. "jax" will load the weights in the jax
                        format. "safetensors" will load the weights in the
                        safetensors format. "npcache" will load the weights in
                        jax format and store a numpy cache to speed up the
                        loading. "dummy" will initialize the weights with
                        random values, which is mainly for profiling."gguf"
                        will load the weights in the gguf format.
                        "bitsandbytes" will load the weights using
                        bitsandbytes quantization."layered" loads weights
                        layer by layer so that one can quantize a layer before
                        loading another to make the peak memory envelope
                        smaller.

                        Pathways PD. 'cache_aware' routes by cache affinity
